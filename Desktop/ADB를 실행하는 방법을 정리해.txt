좋아요! **컴퓨터를 재부팅한 후 ADB를 실행하는 방법**을 정리해 드릴게요.  
컴퓨터를 다시 켜면 ADB 서버가 종료되므로, 다음 과정을 거쳐 다시 연결해야 합니다.  

---

### ✅ **컴퓨터 재부팅 후 ADB 실행하는 방법**  

#### **1. ADB 서버 실행 및 디바이스 연결**
🔹 **명령 프롬프트 열기**  
   - `Win + R` → `cmd` 입력 후 실행  
   - 또는 Windows 검색에서 `cmd`를 찾아 실행  

🔹 **ADB 서버 시작하기**  
   ```
   adb start-server
   ```

🔹 **디바이스 연결 확인**  
   ```
   adb devices
   ```
   - 디바이스가 목록에 나타나면 정상적으로 연결된 것입니다.

#### **2. 에뮬레이터 연결 (필요한 경우)**
🔹 **에뮬레이터가 실행 중인지 확인**  
   ```
   emulator -list-avds
   ```
   - 현재 사용 가능한 가상 디바이스 목록을 확인할 수 있습니다.  

🔹 **에뮬레이터 실행하기**  
   ```
   emulator -avd <AVD_NAME>
   ```
   - `<AVD_NAME>` 부분에 실제 사용 중인 에뮬레이터 이름을 입력하세요.  

🔹 **포트 활성화 및 ADB 연결**  
   ```
   adb -s emulator-5554 tcpip 5555
   adb connect 127.0.0.1:5555
   ```

#### **3. 연결 유지 자동화 (옵션)**
🔹 **자동 실행 배치 파일 생성 (Windows)**
   - `adb_restart.bat` 파일을 만들고 아래 내용을 저장하세요:
     ```
     @echo off
     adb start-server
     adb connect 127.0.0.1:5555
     adb devices
     ```
   - 파일을 실행하면 자동으로 ADB 연결이 설정됩니다.

🔹 **자동 실행 설정 (Windows 시작 시)**
   - `adb_restart.bat` 파일을 Windows 시작 프로그램에 추가하면 부팅할 때 자동 실행됩니다.

---

이제 컴퓨터를 재부팅해도 **ADB와 에뮬레이터를 쉽게 다시 연결**할 수 있을 거예요!  
추가로 궁금한 점이 있다면 언제든지 알려 주세요. 😊

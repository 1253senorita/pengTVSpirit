보낸 사람 Copilot:
좋아요! Windows 10에서 PowerShell을 사용하여 AWS 자격 증명을 설정하는 방법을 단계별로 안내해드리겠습니다.

1. PowerShell 터미널 열기
Windows + X: Windows 키와 X 키를 동시에 누른 후, 나타나는 메뉴에서 Windows PowerShell 또는 Windows PowerShell (Admin)을 선택합니다.
Windows + R: Windows 키와 R 키를 동시에 눌러 실행 창을 열고, powershell을 입력한 후 Enter 키를 누릅니다.
2. 홈 디렉토리로 이동
PowerShell 터미널에서 홈 디렉토리로 이동합니다. 홈 디렉토리는 C:\Users\YourUsername에 위치합니다.
cd ~

또는
cd C:\Users\YourUsername

3. .aws 폴더 생성
홈 디렉토리에 .aws 폴더를 생성합니다.
mkdir .aws

4. credentials 파일 생성
.aws 폴더로 이동합니다.
cd .aws

credentials 파일을 생성합니다.
New-Item -Path . -Name "credentials" -ItemType "File"

5. credentials 파일 열기
credentials 파일을 텍스트 편집기로 엽니다. 예를 들어, 메모장을 사용하여 파일을 열 수 있습니다.
notepad credentials

6. 자격 증명 추가
credentials 파일에 다음 내용을 추가합니다:
[default]
aws_access_key_id = YOUR_ACCESS_KEY_ID
aws_secret_access_key = YOUR_SECRET_ACCESS_KEY

파일을 저장하고 닫습니다.
이제 AWS 자격 증명이 설정되었습니다. 도움이 되셨길 바랍니다! 😊

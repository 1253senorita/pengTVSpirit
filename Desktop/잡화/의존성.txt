### 프로젝트 단 역할 추가 설명
#### 1. **루트 프로젝트 정의**
루트 프로젝트에서는 전체 프로젝트 구조와 주요 의존성 관리가 이루어집니다.
- 저장소 정의: 모든 의존성을 검색할 저장소(`google()`, `mavenCentral()`)를 설정.
- Version Catalog: 주요 라이브러리 버전과 이름을 중앙에서 관리.

#### 2. **앱 모듈 정의**
앱 모듈에서는 실제 애플리케이션과 관련된 라이브러리를 참조합니다.
- UI 구성 라이브러리: Jetpack Compose와 관련된 모든 UI 라이브러리를 참조.
- 기능별 라이브러리: Firebase, 네트워킹, 데이터베이스와 같은 기능 구현에 필요한 라이브러리를 참조.

#### 3. **멀티 모듈 정의**
멀티 모듈 프로젝트에서는 `settings.gradle.kts`에서 모듈을 포함하고, 각 모듈별로 의존성을 관리합니다.
- 루트 프로젝트에서 공통 모듈이나 라이브러리를 정의하여 여러 모듈에서 재사용.

### 사용 예시

#### `settings.gradle.kts`
```kotlin
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
    }
    versionCatalogs {
        create("libs") {
            library("androidx-core", "androidx.core", "core-ktx").version("1.9.0")
            library("compose-ui", "androidx.compose.ui", "ui").version("1.4.3")
        }
    }
}
include(":app")
include(":sharedModule")
```

#### `libs.versions.toml`
```toml
[versions]
androidx-core = "1.9.0"
compose-ui = "1.4.3"

[libraries]
androidx-core = { group = "androidx.core", name = "core-ktx", version.ref = "androidx-core" }
compose-ui = { group = "androidx.compose.ui", name = "ui", version.ref = "compose-ui" }
```

#### `app/build.gradle.kts`
```kotlin
dependencies {
    implementation(libs.androidxCore) // Core 라이브러리 참조
    implementation(libs.composeUi)   // Compose UI 참조
}
```

### 확장된 사용 예시

#### 1. 플러그인 관리 (`settings.gradle.kts`와 연결)
```kotlin
dependencyResolutionManagement {
    versionCatalogs {
        create("libs") {
            plugin("android-application", "com.android.application").version("8.0.0")
            plugin("kotlin-android", "org.jetbrains.kotlin.android").version("1.8.10")
        }
    }
}
```

#### 2. `libs.versions.toml` 파일 예시
```toml
[versions]
androidx-core = "1.9.0"
compose-ui = "1.4.3"
firebase-auth = "21.1.0"
retrofit = "2.9.0"
room-runtime = "2.5.0"
glide = "4.15.0"
localization = "1.2.0"

[libraries]
androidx-core = { group = "androidx.core", name = "core-ktx", version.ref = "androidx-core" }
compose-ui = { group = "androidx.compose.ui", name = "ui", version.ref = "compose-ui" }
firebase-auth = { group = "com.google.firebase", name = "firebase-auth", version.ref = "firebase-auth" }
network-retrofit = { group = "com.squareup.retrofit2", name = "retrofit", version.ref = "retrofit" }
db-room-runtime = { group = "androidx.room", name = "room-runtime", version.ref = "room-runtime" }
media-glide = { group = "com.github.bumptech.glide", name = "glide", version.ref = "glide" }
localization-lib = { group = "com.example.localization", name = "localization", version.ref = "localization" }
```

#### 3. `app/build.gradle.kts` 연결
```kotlin
plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.android)
}

    implementation(libs.androidxCore)   // AndroidX Core
    implementation(libs.composeUi)     // Jetpack Compose
    implementation(libs.firebaseAuth)  // Firebase Auth
    implementation(libs.networkRetrofit) // Retrofit for networking
    implementation(libs.mediaGlide)    // Glide for image processing
    implementation(libs.localizationLib) // Localization library
}
```

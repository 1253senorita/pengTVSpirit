🔹 **GitHub에서 검색**  
👉 원하는 기능을 포함한 프로젝트 찾기 ([GitHub 검색 링크](https://github.com/search?q=android+firebase&type=repositories))  

🔹 **Git 명령어로 클론**  
```powershell
git clone https://github.com/alexmamo/FirebaseSignInWithGoogle.git firebase_auth_project_v2

## ✅ **4. Gradle 설정 업데이트 (라이브러리 추가)**

}
```
👉 Firebase 인증 기능을 사용할 수 있도록 설정 추가

## ✅ **5. Firebase 인증 기능을 코드에 적용**  
가져온 코드가 오빠의 프로젝트에서 정상 작동하도록 수정합니다.  

🔹 **Firebase 인스턴스 초기화 (`MainActivity.kt`)**  
```kotlin
private lateinit var auth: FirebaseAuth

override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    auth = Firebase.auth
}
```

🔹 **로그인 기능 적용 (`AuthHelper.kt` 파일 생성 후 추가)**  
```kotlin
fun signIn(email: String, password: String) {
    FirebaseAuth.getInstance().signInWithEmailAndPassword(email, password)
        .addOnCompleteListener { task ->
            if (task.isSuccessful) {
                Log.d("FirebaseAuth", "로그인 성공: ${task.result?.user?.email}")
            } else {
                Log.e("FirebaseAuth", "로그인 실패: ${task.exception}")
            }
        }
}
```
👉 가져온 프로젝트의 코드 구조를 참고해, **오빠의 프로젝트에서 인증 기능을 직접 구현**합니다.

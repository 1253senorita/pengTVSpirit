GitHub 프로젝트 업로드 및 백업 정리
GitHub에 로그인: GitHub 계정에 로그인합니다.

새 저장소 만들기: 페이지 우측 상단의 "+" 버튼을 클릭한 후, "새 저장소(New repository)"를 선택합니다.

저장소 설정: 저장소 이름을 입력하고, 공개 여부를 설정한 후, "저장소 만들기(Create repository)" 버튼을 클릭합니다.

프로젝트 디렉토리 이동:

bash
cd "C:\\Users\\55341\\AndroidStudioProjects\\VmRetroApp"
로컬 저장소 초기화:

bash
git init
파일 추가 및 커밋:

bash
git add .
git commit -m "First commit"
원격 저장소 연결:

bash
git remote add origin https://github.com/your-username/your-repository.git
코드 푸시:

bash
git push -u origin master
다음 작업을 위한 GitHub 사용 방법
GitHub 저장소에 접속: GitHub에 로그인 후, 해당 저장소 페이지로 이동합니다.

새로운 변경 사항 추가:

파일 추가 및 커밋:

bash
git add .
git commit -m "설명 메시지"
변경 사항 푸시:

bash
git push
예시
터미널 또는 명령 프롬프트에서 프로젝트 디렉토리로 이동:

bash
cd "C:\\Users\\55341\\AndroidStudioProjects\\VmRetroApp"
변경 사항을 추가하고 커밋:

bash
git add .
git commit -m "Update project files"
변경 사항을 원격 저장소에 푸시:

bash
git push
이렇게 정리된 내용을 참고하시면 다음에도 쉽게 GitHub를 사용하여 프로젝트를 관리

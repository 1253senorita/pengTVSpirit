실히 과정을 정리해두면 나중에 다시 작업할 때 도움이 됩니다. 다음은 Firebase Admin SDK를 설치하고 다시 실행하는 과정을 정리한 것입니다:

프로젝트 디렉토리로 이동:
                              
bash
cd "C:\Users\55341\AndroidStudioProjects\AuthTestFF"
Firebase Admin SDK 설치:

bash
npm install firebase-admin --save
설치가 완료되면 174개의 패키지가 추가되고, 19개의 패키지는 자금을 요청합니다. 이를 확인하려면 npm fund 명령을 실행하세요.

npm 최신 버전으로 업데이트:

bash
npm install -g npm@11.1.0
이 과정에서 새 버전의 npm을 설치하여 최신 상태로 유지합니다.

프로젝트 실행: 프로젝트 디렉토리에서 다음 명령을 사용하여 프로젝트를 실행할 수 있습니다:

bash
npm start

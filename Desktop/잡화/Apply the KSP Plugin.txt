Apply the KSP Plugin:
In your module-level build.gradle.kts file, apply the plugin:

plugins {
    // Other plugins
    alias(libs.plugins.ksp)
}


@@@@@@@@@@@@

2

Add KSP Processor Dependencies:
Also in your module-level build.gradle.kts, in the dependencies block:


dependencies {
    // Other dependencies
    ksp(libs.hilt.compiler)
    ksp(libs.androidx.room.compiler)
}


@@@@@@@@@@@@@@@@

**단계**  
1. `libs.versions.toml` 파일의 해당 섹션([versions], [plugins], [libraries])에 필요한 의존성을 추가하십시오.  
2. `build.gradle.kts` 파일의 `plugins` 섹션에 플러그인을 추가하십시오.  
3. `build.gradle.kts` 파일의 `dependencies` 섹션에 의존성을 추가하십시오.  

**주요 요점**  
- KSP 플러그인(`com.google.devtools.ksp`)은 프로젝트에 적용하는 플러그인입니다.  
- KSP 프로세서(예: Hilt, Room)는 `ksp` 구성으로 사용하는 의존성입니다.  
- 버전 카탈로그를 사용하면 이러한 요소를 중앙에서 간편하게 관리할 수 있습니다.

Steps
Add the dependencies in the file libs.versions.toml, in the corresponding sections: [versions], [plugins] and [libraries].
Add the plugin in the file build.gradle.kts, in the section plugins.
Add the dependencies in the file build.gradle.kts, in the section dependencies.
Key Takeaways
The KSP plugin (com.google.devtools.ksp) is a plugin you apply.
KSP processors (like Hilt's, Room's) are dependencies that you use with the ksp configuration.
Version catalogs make it very easy to manage these in one central location.
